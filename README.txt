Karice Carousel for Elementor

Standalone Elementor widget with Swiper-powered effects and repeater slides.

What's new in 1.1.1
- Per-slide background media support
- Image backgrounds
- Video backgrounds from the media library or direct MP4/WebM URL
- Optional poster image for background video
- Per-slide overlay color
- Background slide min-height and content width style controls

Usage
1. Install and activate Elementor.
2. Install and activate this plugin.
3. In Elementor, search for “Karice Carousel”.
4. Add slides in the repeater.
5. For each slide, choose Background Media: None, Image Background, or Video Background.
6. For video backgrounds, use a media-library video or a direct MP4/WebM URL.

Theme Options
- Open `Appearance > Karice Theme Options`.
- Enable or disable Karice Elementor widgets globally.
- Set whether taxonomy add forms (capability, space, fixture) are collapsed by default.
